# 安全说明

## 面板内置的安全措施

1. **密码强度**：默认生成 32 位 hex 或 24 字节 base64 随机密码，覆盖安装时可保留旧值。
2. **密码不回显**：部署时输入密码使用 `read -s`，不会显示在终端，也不会进入 shell 历史。
3. **文件权限**：
   - 配置目录 `700`，配置文件/私钥/分享链接 `600`
   - 通过 `umask 077` 全局保证新建文件默认仅所有者可读写
4. **证书**：ECDSA P-256 自签证书，仅用于 TLS 握手，客户端跳过验证即可。
5. **防火墙**：部署时自动放行协议端口；「一键收紧」仅保留 SSH(22) + 协议端口。
6. **更新校验**：git 方式更新使用 `reset --hard origin/main`，避免本地篡改残留。

## 建议你手动做的事

- 用面板「安全检查」跑一遍，按报告整改
- SSH 改用密钥登录后，关闭密码认证（`PasswordAuthentication no`）
- 安装 `fail2ban` 防 SSH 爆破：`apt install fail2ban`
- 定期 `apt update && apt upgrade` 打补丁
- 分享链接等同于密码，不要发到公开群组；泄露后用面板重新部署更换密码

## 不做的事（有意为之）

- 面板不会自动修改你的 SSH 配置（改错会导致失联，风险太高）
- 面板不会上传任何数据，所有操作都在本机完成
